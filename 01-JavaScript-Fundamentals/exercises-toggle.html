Exercise 1 — Declare and log

Declare three variables:
- name holding your name
- age holding your age
- isStudent holding true
Log all three values to the console.

Answer: 
let name = "Marta";
let age = 21;
let isStudent = true;

console.log(name);
console.log(age);
console.log(isStudent);

This creates three variables and logs their values using console.log().

Exercise 2 — typeof inspector

Predict the output of each typeof expression, then verify in the console:

typeof 42
typeof "hello"
typeof true
typeof undefined
typeof null
typeof {}
typeof []
typeof function() {}
Answer: 
typeof 42            // "number"
typeof "hello"       // "string"
typeof true          // "boolean"
typeof undefined     // "undefined"
typeof null          // "object"
typeof {}            // "object"
typeof []            // "object"
typeof function(){}  // "function"

Note: null reports as "object" because of a historical JavaScript quirk.

Exercise 3 — const vs let

What happens when this runs and why?

const PI = 3.14159;
PI = 3;
console.log(PI);
Answer: 
TypeError: Assignment to constant variable.

The code throws an error on line 2 because PI is declared with const.
